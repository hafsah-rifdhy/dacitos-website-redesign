# Dacitos Website Redesign

A modern, responsive redesign of the Dacitos company website, created as part of a frontend development task.

The project focuses on delivering a clean, modern digital experience with responsive layouts, smooth animations, interactive elements, and a strong visual identity.

## About the Project

This project is a redesign of the Dacitos website with an emphasis on modern UI/UX, responsiveness, performance, and engaging interactions.

The website presents Dacitos as a modern digital engineering company through a dark visual theme, gradient accents, animated elements, and structured content sections.

## Features

- Fully responsive layout
- Modern dark-themed interface
- Responsive navigation bar
- Animated hero section
- Interactive visual effects
- Smooth animations and transitions
- Services section
- Technologies section
- Projects showcase
- Process section
- Testimonials section
- Call-to-action section
- Responsive footer
- Mobile-friendly design

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Vercel
